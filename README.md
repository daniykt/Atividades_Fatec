## 📋 Sobre o Projeto

Aplicação web para postagem e visualização de memes, desenvolvida como atividade prática utilizando React. O sistema permite realizar upload de imagens, cadastrar informações do meme e visualizar os conteúdos publicados em um feed moderno e responsivo.

## 🚀 Como Executar

**Pré-requisitos:** Node.js instalado

```bash
# Instalar dependências
npm install

# Rodar em modo desenvolvimento
npm run dev
```

Acesse:

```txt
http://localhost:5173
```
